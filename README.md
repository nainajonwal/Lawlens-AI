# LawLens — AI-Powered Legal Intelligence Platform for Lawyers

LawLens is an AI-assisted legal intelligence and decision-support platform for lawyers.
It helps analyse case documents, retrieve relevant precedents, map applicable laws,
detect evidence contradictions, generate case timelines, assess relative case risk,
prioritize cases, and answer legal research questions with source-grounded AI.

**LawLens does not replace lawyers or judges, and does not predict case outcomes.**
All AI-generated insights require lawyer verification before use.

## Status
🚧 Under active development (college research project).

## Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: FastAPI (Python)
- Database: MySQL
- LLM: Google Gemini API
- RAG: LangChain + FAISS + Sentence-Transformers
